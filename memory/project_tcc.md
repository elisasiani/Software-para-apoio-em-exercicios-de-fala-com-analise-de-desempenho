App Flutter (branch `versao-atualizada-mobile`) que permite pacientes gravar exercícios de fala prescritos por fonoaudiólogos. Usa Firebase Auth, Cloud Firestore e gravação de áudio (package `record`).

**Why:** TCC de fonoaudiologia — paciente grava voz, fono vê no web.

**How to apply:** O Dart SDK instalado é 3.11.0 (Flutter 3.41.2). O pubspec.yaml precisa de `sdk: ^3.11.0`.
